## What I'm Building

### Geodetta
A vendor-neutral **project continuity and cross-tool change-impact platform** designed to reduce the fragmentation that happens when project knowledge is scattered across email, chat, work tracking, documentation, and source control.

The core idea is to connect project communication and decisions across systems such as **Outlook, Teams, Jira, and GitHub**, so teams can see how a conversation, decision, requirement, or change affects the rest of the project lifecycle.
